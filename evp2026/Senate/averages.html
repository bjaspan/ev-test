State Averages for Senate

This page contains the current averages for each state for all the Senate races calculated using our algorithm. It is worth noting that our average may differ from other published averages (RCP etc.) because each site has a different algorithm. Some average the most recent 3 or 4 or some other number of polls, no matter how old they are. Others use time as the primary criterion for inclusion or not. Also, different sites use different polls. We try to rigorously exclude polls from firms that are basically campaign consultants, that is, whose business model is to help elect candidates. Not everyone excludes these. All these differences in methodology can lead to different results.

In the Senate polls below, an asterisk denotes an incumbent.
